# LoanFlow – Enterprise Loan Origination & Approval Management System

LoanFlow is an enterprise-style banking application designed to manage loan applications, eligibility assessment, multi-level approval workflows and repayment processing.

## Technology Stack

- C# and .NET 10
- ASP.NET Core Web API
- Entity Framework Core
- Microsoft SQL Server
- Clean Architecture
- JWT Authentication
- NUnit and Moq
- Serilog and Hangfire
- Docker
- GitHub Actions
- Microsoft Azure

## Project Architecture

- **LoanFlow.API:** REST API endpoints and middleware.
- **LoanFlow.Application:** Application services and interfaces.
- **LoanFlow.Domain:** Domain entities and business rules.
- **LoanFlow.Infrastructure:** Database and external integrations.
- **LoanFlow.Tests:** Unit and integration testing.

## Planned Features

- Customer management
- Loan application management
- Loan eligibility assessment
- Risk assessment
- Multi-level approval workflows
- EMI calculation
- Repayment tracking
- Audit logging
- Cloud deployment
